# Department Analysis SQL Project

## 📌 Project Overview

This project analyzes employee and department data using MySQL.

The main objective is to identify departments that have more employees than the average employee count across all departments.

## 🛠️ Technologies Used

- MySQL
- SQL

## 📚 SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- JOIN
- GROUP BY
- HAVING
- Subqueries
- Aggregate Functions
  - COUNT()
  - AVG()
  - MAX()
  - MIN()

## 📊 Analysis

The project displays:

- Department Name
- Location
- Employee Count
- Average Salary
- Maximum Salary
- Minimum Salary

## 🎯 Result

Based on the given data, the Finance department has more employees than the average employee count across all departments.
